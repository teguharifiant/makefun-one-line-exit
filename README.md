A one-line resignation letter from an IT support worker. It opens with the trade's oldest advice — "turn it off and on again" — and lands the punch on the one thing that actually needed restarting: the career.

## The entry

> I hereby resign from IT support: I have turned it off and on again, and it turns out the thing that needed restarting was my career.

Character count: 132 (code points, single line, ASCII only).

## How to run it

Requires Node.js 22, no dependencies.

```sh
node main.ts
```

This validates the entry and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output`).

## Determinism

The entry text is a fixed constant in `main.ts`. Running the program twice produces byte-identical `entry.txt` files (verified with `cmp`).
